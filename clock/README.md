# ChromaClock 仕様書 (Application Specification)

## 1. アプリケーション概要

| 項目 | 内容 |
| :--- | :--- |
| **アプリ名** | **ChromaClock** (クロマクロック) |
| **概要** | リアルタイムの時間経過とともに空と光のグラデーションが滑らかに移り変わる、モダンで洗練されたプレミアム時計Webアプリケーション |
| **主要ターゲット** | デスクワーク時の卓上時計、作業用BGM・環境アプリ、サイネージ、リラックス用ディスプレイ |
| **技術スタック** | HTML5 / Vanilla CSS3 / Vanilla JavaScript (ES6+) / Web Audio API |
| **外部依存** | Google Fonts (`Space Grotesk`, `Outfit`, `Inter`) のみ（ライブラリ非依存） |

## 3. UI/UX & デザイン仕様

### 3.1 タイポグラフィ
- **時間表示 (Hero Clock)**: `Space Grotesk` (700 Bold)
  - 等幅数字設定: `font-variant-numeric: tabular-nums` (数値変化時の横ブレを完全防止)
  - サイズ: `clamp(6.2rem, 16.5vw, 13.5rem)` によるダイナミックな巨大表示
  - グラデーション文字塗り: `-webkit-background-clip: text` & `background-clip: text`
- **UI & ボディテキスト**: `Outfit` (幾何学的で視認性の高いモダンサンセリフ)
- **メタ・システム情報**: `Inter` (クリーンで機能的なUIフォント)

### 3.2 オーロラグラデーション & 背景演出
- **4基の独立浮遊オーブ (`.aurora-orb`)**:
  - それぞれ異なる軌道・周期（24s〜30s）で拡大・回転・平行移動しながら有機的に混色
  - `filter: blur(85px)` による柔らかなオーロラ効果
- **フィルムグレインテクスチャ (`.noise-overlay`)**:
  - 軽量なインラインSVGフラクタルノイズを `mix-blend-mode: overlay` でブレンドし、高級感のある質感を付与

### 3.3 ガラスモーフィズム (Glassmorphism)
- カード・ドック・ドロワーに採用:
  - `background: rgba(255, 255, 255, 0.07)`
  - `backdrop-filter: blur(32px) saturate(190%)`
  - 微細なトップハイライトボーダー (`border: 1px solid rgba(255, 255, 255, 0.16)`)
  - 浮遊感を演出する多重ドロップシャドウ

### 3.4 レスポンシブ対応
- スマートフォン (〜768px)、タブレット、PC、フルスクリーン表示に完全対応
- 画面サイズに応じてフォントサイズ、パディング、ドックのレイアウトを自動調整

## 4. 機能仕様

### 4.1 時計表示機能
- **時・分・秒表示**:
  - 24時間表記 / 12時間表記（AM/PMバッジ付き）の切り替え対応
  - 秒数（`:SS`）の表示 / 非表示トグル
  - コロン（`:`）のパルス呼吸アニメーション
- **日付・カレンダー表示**:
  - 英語表記: `[Weekday] • [Month] [Date], [Year]`
  - 和暦・六曜併記: `令和〇年 〇月〇日 (曜)`
- **本日の経過率 (Day Progress)**:
  - 00:00:00 〜 23:59:59 までの経過パーセンテージ（例: `27.4%`）
  - 連動するグラデーションプログレスバー
- **インスピレーション名言ティッカー**:
  - 時間や人生に関する名言が16秒ごとに滑らかにクロスフェード更新

### 4.2 24時間スカイ補間カラーエンジン (Dynamic Sky Engine)
現在時刻（時・分・秒）の小数値に基づき、以下のキーフレームカラー間をリアルタイム線形補間（RGB Lerp）してCSSカスタムプロパティを更新：

| 時間帯 | フェーズ名 | 特徴カラー | アイコン |
| :--- | :--- | :--- | :---: |
| **00:00〜04:30** | Midnight Serenity | 深夜のディープインディゴ・星雲パープル | ✨ |
| **04:30〜05:45** | Pre-Dawn Violet | 夜明け前のトワイライトバイオレット | 🌌 |
| **05:45〜06:45** | Dawn Blue Hour | 朝焼け直前の澄んだブルーアワー | 🌅 |
| **06:45〜08:30** | Sunrise Glow | 朝日の温かなコーラル・ゴールド・ピーチ | 🌄 |
| **08:30〜12:00** | Morning Radiance | 清々しいフレッシュシアン・ライトブルー | ☀️ |
| **12:00〜15:30** | Zenith Noon | 晴天のアズール・エメラルドターコイズ | 🌤️ |
| **15:30〜17:30** | Afternoon Amber | 傾き始めた陽光のアンバー・ゴールド | ⛅ |
| **17:30〜19:00** | Golden Twilight | 夕暮れのマゼンタ・バーニングサンセット | 🌇 |
| **19:00〜21:00** | Magic Hour | 夕闇のマジックアワー・ベルベットパープル | 🌆 |
| **21:00〜24:00** | Nightfall Indigo | 静寂のサファイアナイト | 🌙 |

### 4.3 タイムワープシミュレーター (`Preview` ボタン)
- ドロワー内のシミュレータースライダー（0:00 〜 23:59）をドラッグすることで、**1日のグラデーション変化を自由にタイムトラベル体験**可能
- 「リアルタイムに戻す」ボタンで現在時刻の自動追従へ瞬時に復帰

### 4.4 プリセットテーマ切り替え (`Theme` ボタン)
- **時刻連動 (Dynamic)**: 実際の時間帯に合わせて自動変化（デフォルト）
- **極光オーロラ (Aurora Borealis)**: シアン、ブルー、エメラルドグリーンの極光
- **黄昏サンセット (Golden Sunset)**: 鮮やかなピンク、レッド、オレンジ
- **サイバーネオン (Cyber Midnight)**: ネオンピンク、エレクトリックパープル、シアン
- **ドリーミーパステル (Dreamy Sky)**: パステルラベンダー、ソフトピンク、ピーチ

### 4.5 アンビエントサウンドシンセサイザー (`Sound` ボタン)
- **Web Audio API** によるリアルタイム音響合成（外部音声ファイルのDL不要）
- **ピンクノイズ生成アルゴリズム (Paul Kellet's Filter)** ＋ ローパスフィルター (450Hz)
- 心地よい雨音や穏やかな風のようなリラックス環境音を生成
- 指数関数的フェードイン／フェードアウト処理

### 4.6 フルスクリーン & ショートカット操作
- **Full ボタン**: ブラウザ全画面モードへの切り替え
- **キーボードショートカット**:
  - `F`: フルスクリーンのトグル
  - `S`: 秒数表示のトグル
  - `H`: 12時間 / 24時間フォーマットのトグル

## 5. 動作確認 & 起動手順

### ローカルサーバーでの実行
プロジェクトルートまたは `Clock` ディレクトリにて HTTP サーバーを起動します：

```bash
# プロジェクトルートで起動する場合
python3 -m http.server 4321

# ブラウザアクセス
http://localhost:4321/Clock/
```
